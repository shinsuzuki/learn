# Step 1: 開発・実行環境のセットアップ
## 1. IISとASP機能の有効化

1. キーボードの **`Win + R`** を押し、`optionalfeatures` と入力して **Enter** を押します（「Windowsの機能」ウィンドウが開きます）。
2. 一覧から **「インターネット情報サービス」** を探して展開します。
3. 以下の項目にチェックを入れます：
* **Web 管理ツール** ＞ **IIS 管理コンソール**
* **ワールド ワイド ウェブ サービス** ＞ **アプリケーション開発機能** ＞ **ASP**（※「ISAPI 拡張」なども自動でチェックが入ります）


4. **「OK」** をクリックし、変更の適用とインストールが完了するまで待ちます。

## 2. IIS 管理コンソールの起動

1. **`Win + R`** を押し、`inetmgr` と入力して **Enter** を押します。
2. **「インターネット情報サービス (IIS) 管理者」** ウィンドウが起動します。

## 3. ASPエラーのブラウザ送信設定（最重要）

1. 左側のツリーから、ローカルコンピューター名（または特定のWebサイト）を選択します。
2. 中央の機能一覧から **「ASP」** をダブルクリックして開きます。
3. **「デバッグのプロパティ」** のカテゴリを展開します。
4. **「エラーをブラウザに送信」** の項目を **`True`** に変更します。
5. 右側の操作パネルにある **「適用」** をクリックします。

## 4. HTTP 500 カスタムエラーの詳細表示設定

デフォルトのIISでは、サーバー内部エラーが起きた際に「500 - 内部サーバー エラー」という汎用ページに差し替えられてしまいます。これを詳細メッセージに切り替えます。

1. IIS管理コンソールの機能一覧から **「エラー ページ」** をダブルクリックして開きます。
2. 右側の操作パネルから **「機能設定の編集...」** をクリックします。
3. 「エラー応答」の選択肢で **「詳細なエラー」** にチェックを入れ、**「OK」** をクリックします。

## 5. 動作確認用のASPファイル作成

設定が正しく反映されたか確認するため、意図的にエラーを起こすファイルを作成します。

1. `C:\inetpub\wwwroot\` 配下に `errortest.asp` というファイルを作成します。
2. 以下のコード（未宣言の変数を使ってエラーを起こすコード）を記述して保存します。

```asp
<%@ Language="VBScript" OptionExplicit %>
<%
    ' Option Explicit なのに Dim で宣言していない変数に代入
    myVar = "エラーテスト"
    Response.Write myVar
%>

```

3. ブラウザで `http://localhost/errortest.asp` にアクセスします。
4. 画面上に **`Microsoft VBScript 実行時エラー`** や **`変数が定義されていません`** といった行番号付きの具体的なエラーメッセージが表示されれば設定完了です。

---

### トラブルシューティング（エラーが出ない場合）

* **Edge や Chrome 側で汎用エラーに差し替えられる場合:**
ブラウザの開発者ツール（F12）を開き、ネットワークタブでレスポンスの生のHTMLデータを確認してください。
* **権限エラー（HTTP 401 / 403）が出ている場合:**
`C:\inetpub\wwwroot` フォルダのアクセス権限（`IUSR` または `IIS_IUSRS` への読み取り許可）を確認してください。
